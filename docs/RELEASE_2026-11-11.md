# XR Creations 0.1 — release record

Date: 2026-11-11 (Asia/Shanghai)

## What this release contains

- A real public launchpad, replacing a GitHub Markdown test table as the Portfolio Apps destination.
- Twenty original links, searchable by name, mechanism, device and the Hand Lab aliases; comparison versions live in the research catalogue.
- Four studies sharing a state machine, rendering/input layer and finite-event audio: Held Resonance, Score Foundry, Palm Atlas and Garden of Signals.
- Warlock as an existing fan-study entry; Titan and Hunter as plans. A local sound-slot desk assigns audition clips to six event roles per class, without uploading or persisting the files.
- A small, dependency-free static build with source-commit provenance.

## Checks before publication

- Fifteen existing hand-input and new study-state tests pass.
- All public JavaScript passes syntax checks; twelve local HTML links resolve; the static site builds.
- Browser homepage inspection: visual hierarchy, class switching, Phalanx search, empty results and clear-search recovery pass.
- Browser interaction checks complete all four studies: six releases in Held Resonance, eight events in Score Foundry, seven ordered symbols in Palm Atlas, and six pulses followed by three seconds after release in Garden of Signals. Wrong-order symbol feedback, replay and reset were also checked.
- The homepage and Studio fit a 375 px content viewport without horizontal overflow. The mobile homepage, Studio and Portfolio Apps gateway were visually inspected together.
- Real browser PCM validation of the accompanying Hand / Synth / Space repair: seven of seven native OfflineAudioContext cases pass. See [the audio release record](https://github.com/ewanqian/performable-music/blob/main/spatial-playground/hand-osc-lab/AUDIO_RELEASE_2026-11-11.md).
- Twenty legacy entry pages returned HTTP 200 with matching titles. The module closure audit identified one publication omission: `protocols/show-score.mjs`, needed by Spatial Studies and both Atlas pages. The companion music release fixes its packaging.

The current cloud browser cannot create a WebGL context. Its Studio interaction checks use the explicitly labelled Canvas 2D projection of the same 3D scene. They do not prove the WebGL rendering path, stereo perception, hand accuracy, headset frame rate, or author-approved musical quality. Quest / Vision Pro checks remain open.

## Deployment

Public target: <https://ewanqian.site/xr-creations/>.

The source of all new XR code is this repository. Portfolio's release builder uses an immutable commit from `.github/xr-creations-source.json`; generated copies in that repository must not be edited independently. `release.json` on the public site is the definitive deployed source SHA.

Actual production status, browser completion checks and the published SHA are recorded in the [Portfolio handoff](https://github.com/ewanqian/portfolio/blob/main/docs/portfolio-maintenance-os/handoffs/2026-11-11-xr-creations.md). A successful source commit alone is not a deployment claim.
